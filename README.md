# Laundry Management SaaS — Front-end Prototype

Prototipe front-end React + Vite untuk manajemen transaksi dan tracking status cucian laundry. Data bersifat dummy dan state utama berjalan di browser.

## Jalankan
```bash
npm install
npm run dev
```

Build production:
```bash
npm run build
npm run preview
```

## Login demo
Gunakan nama pengguna apa saja dan kata sandi minimal 4 karakter. Pilih peran Admin atau Pegawai. Login ini hanya simulasi front-end.

## Modul
- Dashboard
- Pelanggan
- Layanan & Harga
- Transaksi
- Tracking cucian
- Pembayaran dan cetak nota
- Laporan dan ekspor CSV

## Batasan
Tidak ada backend, database server, API, autentikasi nyata, pembayaran nyata, atau persistensi lintas perangkat. Refresh dapat mengembalikan data ke data awal. Jangan gunakan untuk data pelanggan nyata.

## Dokumen SOT
Dokumen PRD, UI-GUIDELINE, dan IMPLEMENTATION_PLAN tersedia di folder `SOT/`. Aturan untuk agen pengembangan tersedia di `AGENTS.md` dan `PROMPT_EXECUTION.md`.
